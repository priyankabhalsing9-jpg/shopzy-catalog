# Shopzy - Product Catalog

A modern e-commerce product catalog built with React and Vite.

## Features
- Modular component architecture (components, pages, context, data)
- Client-side routing with React Router
- Add to Cart with quantity control and persistent cart (localStorage)
- Product search and category filter
- Lazy loaded pages and images
- Lightweight SVG images and minified production build
- Responsive design
- Deployed on Vercel

## Tech Stack
React, Vite, React Router

## Run Locally
npm install
npm run dev
